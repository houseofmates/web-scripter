# web-scripter

a browser extension for managing user scripts that customize your web experience.

## what is this?

a browser extension for managing user scripts that customize your web experience.

this is a fork of [violentmonkey/violentmonkey](https://github.com/violentmonkey/violentmonkey) with a redesigned ui.

## original vs. this version

this is a fork of the [violentmonkey/violentmonkey](https://github.com/violentmonkey/violentmonkey) project.

### changes from original

- redesigned the ui with a dark pkm aesthetic. all text is now lowercase. extension renamed from violentmonkey to web-scripter. auto-update checking added.

## installation

download the `.xpi` file from releases and open it in firefox, or load it temporarily via `about:debugging` > this firefox > load temporary add-on.
